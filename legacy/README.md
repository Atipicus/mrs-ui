# Legacy Files - Deprecated

**⚠️ DEPRECATION NOTICE**

This directory contains deprecated files that are no longer used in the MRS Design System.

---

## 📁 Files in this Directory

### `theme.json`

**Status**: ❌ **DEPRECATED** (as of v0.12.0)  
**Replaced by**: Generated tokens via Style Dictionary

#### Why Deprecated?

The `theme.json` file created a dual token system that caused:
- **Inconsistency risk**: Two sources of truth (theme.json + generated tokens)
- **Maintenance overhead**: Changes needed in multiple places
- **Confusion**: Developers unsure which system to use
- **Type safety issues**: Manual JSON didn't benefit from TypeScript types

#### What Replaced It?

All design tokens are now generated by **Style Dictionary** from:

```
src/tokens/source/
├── primitives/      (colors, typography, spacing, radius, motion)
├── semantic/        (theme-aware semantic tokens)
└── component/       (component-specific tokens)
```

These source tokens are transformed into **multiple formats**:
- **CSS Variables** (`src/tokens/generated/css/tokens.css`)
- **SCSS Variables** (`src/tokens/generated/scss/tokens.scss`)
- **TypeScript** (`src/tokens/generated/ts/tokens.js`)
- **JSON** (flat, nested, figma-tokens)

#### Migration Path

If you're using `theme.json` directly:

**❌ Old Way (Deprecated):**
```typescript
import themeTokens from './theme.json';
const primaryColor = themeTokens.colorSchemes.light.palette.primary.main;
```

**✅ New Way (v0.12.0+):**
```typescript
import { colors, typography, shape } from '@atipicus/mrs-ui/theme';

// For colors
const primaryColor = colors.light.primary.main;

// For typography
const fontFamily = typography.fontFamily;

// For shape (border radius)
const borderRadius = shape.md;
```

**🎯 Best Practice (Use Generated Tokens):**
```typescript
import * as tokens from '@atipicus/mrs-ui/tokens';

const primaryColor = tokens.SemanticColorLightPrimaryMain;
const fontFamily = tokens.PrimitivesTypographyFontFamilyStack;
const borderRadius = tokens.PrimitivesRadiusMd;
```

## 🔄 How to Update Your Code

### Step 1: Update Imports

**Replace:**
```typescript
import themeTokens from './theme.json';
```

**With:**
```typescript
import { colors, typography, shape } from '@atipicus/mrs-ui/theme';
```

### Step 2: Update Token References

| Old (theme.json) | New (Generated Tokens) |
|-----------------|------------------------|
| `themeTokens.colorSchemes.light.palette.primary.main` | `colors.light.primary.main` |
| `themeTokens.typography.fontFamily` | `typography.fontFamily` |
| `themeTokens.typography.h1` | `typography.h1` |
| `themeTokens.shape.md` | `shape.md` |
| `themeTokens.spacing[2]` | `spacing[2]` |

### Step 3: Update Theme Configuration

If you're creating custom themes:

**❌ Old:**
```typescript
import themeTokens from './theme.json';
import { createTheme } from '@mui/material';

const myTheme = createTheme({
  palette: {
    primary: {
      main: themeTokens.colorSchemes.light.palette.primary.main,
    },
  },
});
```

**✅ New:**
```typescript
import { createTheme } from '@mui/material';
import { colors } from '@atipicus/mrs-ui/theme';

const myTheme = createTheme({
  palette: {
    primary: {
      main: colors.light.primary.main,
    },
  },
});
```
