# BottomNavigation

Bottom navigation bars allow movement between primary destinations in an app. They are typically used for mobile applications and provide quick access to top-level views.

## Overview

The BottomNavigation component is part of the MRS Design System and wraps Material-UI's BottomNavigation with custom theme tokens. It consists of two components:

- **BottomNavigation**: The container component that manages navigation state
- **BottomNavigationAction**: Individual navigation items within the bar

## When to Use

- **Mobile Navigation**: Primary navigation method for mobile applications
- **3-5 Destinations**: Best suited for 3-5 top-level destinations
- **Persistent Access**: When destinations need to be accessible from anywhere in the app
- **Equal Importance**: All destinations should have similar levels of importance

## When Not to Use

- **More than 5 Items**: Use a navigation drawer instead
- **Hierarchical Navigation**: Use breadcrumbs or back buttons for hierarchical content
- **Desktop Primary Navigation**: Consider AppBar or Drawer for desktop-first applications
- **Sequential Tasks**: Use Stepper for multi-step processes

## Value Management

### Controlled Component

Use state to control which navigation item is selected:

```tsx
const [value, setValue] = useState(0);

<BottomNavigation
  value={value}
  onChange={(event, newValue) => setValue(newValue)}
>
  <BottomNavigationAction label="Recents" icon={<RestoreIcon />} />
  <BottomNavigationAction label="Favorites" icon={<FavoriteIcon />} />
</BottomNavigation>
```

## Props

### BottomNavigation Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `any` | - | The value of the currently selected action |
| `onChange` | `(event, value) => void` | - | Callback fired when the value changes |
| `showLabels` | `boolean` | `false` | If true, all actions will show their labels |
| `children` | `node` | - | BottomNavigationAction components |

### BottomNavigationAction Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `node` | - | The label element |
| `icon` | `node` | - | The icon to display |
| `value` | `any` | - | Custom value (otherwise uses index) |
| `showLabel` | `boolean` | `false` | If true, label is always shown |
| `disabled` | `boolean` | `false` | If true, the action is disabled |

## Accessibility

- Uses semantic HTML with proper button roles
- Supports keyboard navigation (Tab, Enter, Space)
- Labels provide context for screen readers
- Consider providing `aria-label` for icon-only actions

### Best Practices

```tsx
// Good: Labels provide context
<BottomNavigationAction
  label="Home"
  icon={<MaterialSymbol icon="home" ariaLabel="Home" />}
/>

// Better: Use showLabels for better accessibility
<BottomNavigation showLabels>
  <BottomNavigationAction label="Home" icon={<MaterialSymbol icon="home" />} />
</BottomNavigation>
```

## Design Tokens

The BottomNavigation component uses the following design tokens from the MRS theme:

- **Colors**: `palette.primary.main`, `palette.text.secondary`
- **Typography**: Inherited from theme typography
- **Spacing**: `theme.spacing()` for internal padding
- **Transitions**: Smooth transitions for state changes

## Integration with Router

For routing integration (e.g., React Router), use the `component` prop:

```tsx
import { Link } from 'react-router-dom';

<BottomNavigation value={value} onChange={handleChange}>
  <BottomNavigationAction
    label="Home"
    icon={<MaterialSymbol icon="home" />}
    component={Link}
    to="/home"
  />
  <BottomNavigationAction
    label="Profile"
    icon={<MaterialSymbol icon="person" />}
    component={Link}
    to="/profile"
  />
</BottomNavigation>
```

## Responsive Behavior

- Best suited for mobile and tablet viewports
- Consider switching to AppBar or Drawer for desktop layouts
- Use MUI breakpoints to conditionally render navigation types

```tsx
import { useMediaQuery, useTheme } from '@mui/material';

const theme = useTheme();
const isMobile = useMediaQuery(theme.breakpoints.down('md'));

{isMobile ? (
  <BottomNavigation>...</BottomNavigation>
) : (
  <AppBar>...</AppBar>
)}
```
